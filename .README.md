# Repository Guide

This repository holds the **complete MtaaFix** project scaffold.

## Quick Reference

- **Backend**: `backend/` — Spring Boot 25 REST API (Maven).
- **Web**: `web/` — Vite + React + TypeScript.
- **Mobile**: `mobile/` — Flutter (single shared Android + iOS codebase).
- **Documentation**: `docs/` (architecture, API, standards, project-management, roadmap).
- **Templates & CI**: `.github/` (ISSUE_TEMPLATE, PULL_REQUEST_TEMPLATE, workflows).

## Working with this Repository

1. Read `README.md` for the product overview.
2. Review `docs/architecture/ADR_0001_PROJECT_STRUCTURE.md` for the architecture.
3. Use `docs/api/API.md` for the API contract.
4. Check `docs/project-management/ROADMAP.md` for the phased plan.
5. Use `docs/standards/CODING_STANDARDS.md` and `SECURITY_STANDARDS.md` before writing code.

## Branch Strategy

- `master` holds the current active Phase 0.
- Feature work uses `phase/<phase>/<feature>` branches, opened from `master`.
